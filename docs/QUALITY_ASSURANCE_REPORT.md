# Quality Assurance Report

This report states what was checked, how, and what was **not** checked. Nothing here should be read as a claim of testing beyond what is listed.

## 1. Scope delivered

| Item | Count |
|---|---|
| Generated HTML pages | 184 |
| Syllabus topics (Unit I 13, II 16, III 18, IV 17) | 64 |
| Distinct interactive simulations | 73 |
| Virtual experiments | 37 |
| Quiz items (4 unit quizzes) | 82 |

Every syllabus topic has a page with the 14-part template and at least one embedded simulation (see `SYLLABUS_CONTENT_MAPPING.md` and `SIMULATION_CATALOG.md`, both generated by `tools/build.js` directly from the data files, so they cannot drift from the site).

## 2. Automated tests that were run

All tests ran in a Linux container with Node.js and Playwright's **headless Chromium** (WebGL via SwiftShader software rendering).

| Test | What it checks | Result |
|---|---|---|
| `node tests/math.test.js` | 129 numeric checks of the equation engine `js/equation-engine.js`, mostly reproducing the worked examples in the notes (Ex 1.1–1.30, 2.1–2.15, 3.1–3.12, 4.4–4.7) against the answers given there, plus consistency checks (rotation orthonormality, IK round-trip, Jacobian, energy drift of the 2-link dynamics, Otsu threshold) | 129 passed, 0 failed |
| `node tools/build.js` | Every topic/experiment/sim id referenced in data exists; every topic has required sections; no broken internal ids | No problems reported |

## 3. Defects found and fixed during testing (selection)

- Negative first-frame time step produced invalid geometry in the measurement-system sim → time step clamped in the engine.
- Vision inspection falsely rejected good parts (edge pixels counted as scratches, width bias) → two-shot imaging, caliper measurement along the part axis, interior-only scratch test.
- Image-processing classifier confused rectangle/slot → added rectangularity and aspect features.
- Assembly cell readouts reset every cycle; conveyor object leak in industrial-robots sim → fixed.
- `\boldsymbol` in Unit III equations requested a MathJax extension not bundled offline (topics III-14, 15, 17, 18) → replaced with plain `\tau`; Unit III topics 10–18 re-tested with all controls exercised: 0 errors.

## 4. Academic validation

- Content follows the supplied lecture notes; equation numbers from the notes are preserved where the notes give them. Material not in the notes is labelled **Supplementary**.
- Numerical values in examples and simulations are **illustrative teaching values**, not data-sheet values for specific products.
- Several sims use deliberately simplified models (e.g. first-order motor electrical dynamics, ideal op-amps, rigid links, point-mass payloads, synthetic camera images, a generic robot language rather than any vendor's). These are stated in each sim's intro panel.
- The instructor should still review every topic page and quiz answer. Automated tests confirm the code runs and the core maths is self-consistent; they do **not** prove every sentence or every quiz explanation is pedagogically correct.

## 5. Not tested / known limitations

- **Browsers:** only headless Chromium. Not tested on Firefox, Safari, Edge, or any real mobile device/touch screen. Layout was checked at phone width in Chromium emulation only.
- **GPU:** 3D scenes were tested with software WebGL; real-GPU performance on low-end laptops/phones not measured.
- **Accessibility:** keyboard focus and ARIA labels exist on controls, but no screen-reader audit or WCAG contrast audit was performed.
- **GitHub Pages:** links are relative and a `.nojekyll` file is included, but the site was served from a local static server, not from an actual GitHub Pages deployment.
- **MathJax:** bundled offline (`tex-svg.js`); only extensions included in that bundle work. Adding new TeX that needs other extensions (e.g. `\boldsymbol`, `\cancel`) will fail offline.
- **Course code:** the notes show `B24EES502`; other supplied files show different codes. Set the correct one in `js/config.js`.
- No user accounts, no server-side storage: quiz scores and observation tables live only in the browser session (CSV export provided).
- No institutional logos or images are bundled; `assets/` contains only third-party libraries with their licences.
